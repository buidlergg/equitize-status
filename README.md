## Maintenance

Edit `.upptimerc.yml` to change monitors or branding. Setup CI rebuilds the site
when that configuration changes. Uptime CI runs checks every five minutes;
GitHub can delay scheduled jobs. Incidents are tracked as repository issues.

Workflows use the repository-scoped GITHUB_TOKEN. Automatic template rewriting
is disabled because it requires elevated workflow permissions. Review upstream
Upptime updates manually, preserving Pages artifact deployment and the empty
secret allowlist. No personal access token or application credentials are stored.

To remove this setup, disable Actions, remove the custom-domain DNS record,
and delete this repository. It has no ownership of application data or services.
